## 1. The 4-row score gap table (must-have, low-cost)

Saved to `docs/baseline_scores.md`. Row 4 added after Issue #32 training run.

| Agent                                      | Mean score (outcome × efficiency) | Behaviour                                              |
| ------------------------------------------ | --------------------------------- | ------------------------------------------------------ |
| Random baseline                            | ~0.02                             | Random commands; outcome gate fails; score floor.      |
| Qwen2.5-7B (no system prompt)              | ~0.06                             | Some investigation, never plans, fails outcome gate.   |
| Qwen2.5-7B (SRE + MissionOps system prompt) | ~0.18                             | Plans, partial diagnosis, sometimes resolves.          |
| **Qwen2.5-7B (mtGRPO trained on Praxis)** | **~0.31**                         | Plan, save_finding, recall_memory, recover, submit.    |

The **5–8× gap** between rows 1/2 and row 4 is the "training signal exists" proof. Issue #30 owns rows 1–3; Issue #32 appends row 4 after the training run.

Reproduction commands:

```bash
python inference.py --task cascading-platform-failure --runs 5 --seed 2026 --model random
python inference.py --task cascading-platform-failure --runs 5 --seed 2026 --no-system-prompt
python inference.py --task cascading-platform-failure --runs 5 --seed 2026
python inference.py --task cascading-platform-failure --runs 5 --seed 2026 --adapter ./checkpoints/praxis-grpo
```
