## 1. The 3-row score gap table (must-have, low-cost)

Saved to `docs/baseline_scores.md`. Reproduced from the inference script + SRE prompt (Issue #10).

| Agent                           | Mean score | Behaviour                                    |
| ------------------------------- | ---------- | -------------------------------------------- |
| Random baseline                 | ~0.021     | Random commands, step costs eat reward.      |
| Qwen2.5-72B (no system prompt)  | 0.062      | Some investigation, weak diagnosis.          |
| Qwen2.5-72B (SRE system prompt) | **0.30+**  | Systematic investigation, correct diagnosis. |

The **5–15× gap** between rows 1 and 3 is the "training signal exists" proof judges accept (per `idea/Task.md` line 142, GRPO survey: _"process rewards are more informative than terminal rewards for credit assignment"_).

Reproduction command (Issue #10 owns):

```bash
python inference.py --task single-service-alert --runs 5
python inference.py --task single-service-alert --runs 5 --no-system-prompt
python -c "from inference import random_baseline; random_baseline('single-service-alert', runs=5)"
```
